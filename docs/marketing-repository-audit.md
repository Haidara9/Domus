## الإضافة داخل DOMUS

- Agency Agents: Git submodule مثبت على `f99f6aa910a442b0197b768ce0ea7751e35e2060`.
- Video Ad Editor: Git submodule مثبت على `60626fd22f1a47f7705e68e19bcc68ac2a01b417`، الوسم `v4.4.3`.
- Open Edit: النسخة الموجودة في `tools/open-edit` تطابق كل ملفات الأرشيف المرفق؛ لم تُكرر.
- السكّيل `motion-reel`: حفظ نسخة مرفقة غير معدلة كمرجع مشروع، دون مثبت عالمي.
- `marketing/config.json` يحدد ستة أدوار فقط. `context` يجمع المرجع والموجز وتعليمات DOMUS محلياً؛
  لا يشغّل وكلاء ولا يستدعي API. الأرقام التسويقية النموذجية داخل الملفات الأصلية ليست بيانات دوموس.
- تشغيل Hermes على Windows، أو خدمة وكلاء دائمة، أو النشر والترويج الفعلي لم يُنجز بهذه الإضافة.

تُسجل إصدارات المصادر وبصمات الأرشيفات في `marketing/sources.lock.json`.
