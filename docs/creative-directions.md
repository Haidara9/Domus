# Creative direction library

Pick per property, audience and platform. Rotate directions, and check `library/learnings/LOG.md` for what was
used recently. Each direction lists engine settings so it can be built at once. The brand (paper, copper, line
art, calm Arabic voice) stays present in every direction, but at different intensities.

## How to choose (Creative Director)
1. **Property truth:** what is special in the footage? (light → 1/2, views → 2/3, design → 2/7, family life → 5).
2. **Audience:** investors → 3; luxury buyers → 1/2; local families → 5/6; brand awareness → 4/7.
3. **Platform:** Reels/TikTok push toward 3/6 pacing. Website/YouTube allow 1/2/5.
4. **Contrast with the last film:** avoid repeating the previous production's direction unless the client asks.
5. It's fine to blend (e.g. 2 + 6: architectural shots cut at social pace), but name the primary direction.

## DOMUS brand intensity by direction
- Strong (paper cards, bracket, line art): 4, 7, brand films.
- Medium (copper rules, archTitle, end card on paper): 1, 2, 6.
- Light (lower thirds, end card): 3, 5.
