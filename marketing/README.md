# دوموس — إدارة المحتوى والتسويق

هذا مسار عمل محلي لدوموس العقارية في اللاذقية: موجز العقار ← استراتيجية ← هوك وكابشن وCTA ←
ربط الريل بالإنتاج ← مراجعة بشرية ← ملف للنشر اليدوي ← قياس النتائج الفعلية.

**الجاهز الآن:** حفظ الموجز، تحميل سياق دور متخصص، فحص الحقول، ربط الموافقة بالمحتوى والفيديو،
تصدير النص، وحساب مؤشرات من أرقام ذات مصدر. لا يحتاج مفتاح API أو اشتراكاً أو مكتبات إضافية.
**غير متصل:** صفحة Facebook، Instagram، Buffer، حساب الإعلانات أو نموذج توليد مستقل.
التنزيل لا يعني تشغيل خدمة وكلاء دائمة، وملف التصدير لا يعني أن المنشور نُشر.

## البدء

من جذر المستودع، بعد تنزيل المستودعات المثبتة:

```sh
git submodule update --init --recursive
node marketing/bin/domus-marketing.mjs doctor
node marketing/bin/domus-marketing.mjs new my-next-property
node marketing/bin/domus-marketing.mjs context my-next-property copy
```

املأ `brief.json` فقط بمعلوماتك المؤكدة. اترك غير المتاح `null`.
`owner_confirmed` يوثق تأكيد صاحب المعلومات؛ ليس تحققاً مستقلاً من وثائق العقار.
حقول العقار: نوعه، موقعه، مساحته، عدد الغرف، السعر وعملته، والميزات.
لموجز عرض متاح يجب تحديد النوع والموقع؛ يمكن حذف السعر من الإعلان إن لم ترغب بنشره.
للريل: `media.video` هو مسار الفيديو داخل المستودع و`production` رابط مجلد الإنتاج في `productions/`.
لا تعتمد الفيديوهات القديمة على أنها فيديو أول عقار في هذه المهمة دون تحديده من صاحب المشروع.

الأدوار الستة: `strategy`، `copy`، `reels`، `brand`، `ads`، `analytics`.
أمر `context` يحفظ ملف تعليمات يمكن العمل به في Codex أو Claude أو Hermes؛ لا يستدعي نموذجاً ولا يشغل وكيلاً.
الأدوار العامة في Agency Agents تحتاج تكييفاً للسوق المحلي؛ تعليمات دوموس تتقدم عليها.

بعد كتابة `copy.json` ومراجعة الحقائق واللغة والفيديو:

```sh
node marketing/bin/domus-marketing.mjs validate my-next-property
# يُنفّذ التالي فقط بعد موافقة بشرية على النص والفيديو المحددين:
node marketing/bin/domus-marketing.mjs approve my-next-property "اسم المراجع"
node marketing/bin/domus-marketing.mjs export my-next-property
```

يتضمن التصدير `export/post.txt` و`export/publish-packet.json`، بحالة `ready_for_manual_publish`.
تعديل الموجز أو النص أو بايتات الفيديو يستلزم مراجعة جديدة قبل التصدير.
فحص الحقول لا يستطيع إثبات أن كل جملة صحيحة أو أن الفيديو مناسب؛ المراجعة البشرية مطلوبة.
أمر الموافقة سجل محلي وليس نظام صلاحيات أو توقيعاً رقمياً موثق الهوية.

## قواعد المحتوى

- **متاح:** عرض عقار فقط بعد تأكيد توفره؛ CTA للاستفسار أو ترتيب معاينة.
- **تم تأجيره / بيعه:** إعلان إغلاق العرض وتشويق للعقارات القادمة؛ لا دعوة لمعاينة عقار مغلق.
- **حالة غير معروفة:** يبقى الموجز مسودة حتى التأكيد.
- العربية واضحة وقريبة من جمهور اللاذقية، جمل قصيرة، نبرة هادئة. لا «أفضل سعر» أو «عائد مضمون»
  أو ندرة مصطنعة أو شهادات عملاء مخترعة. لا أسعار أو أرقام هواتف من محادثات عقارات أخرى.
- حافظ على Cairo وPlayfair Display والشعار الأصلي. الألوان في `brand.json` رموز عمل مأخوذة من الصور؛
  لا تمثل دليلاً رسمياً لأكواد الطباعة.
- لا تغيّر حقيقة العقار بالصورة أو بالفيديو. لا تصف صور الهوية التوضيحية بأنها عقارات متاحة.

## اقتراح أعمدة المحتوى — للمراجعة

| العمود | المادة | الهدف المقترح |
|---|---|---|
| عقار متاح | ريل بمعلومات مؤكدة | استفسارات مرتبطة بالعقار |
| إعلان التأجير أو البيع | إغلاق العرض وتشويق | تحديث توفر العقارات |
| خدمة دوموس | تعريف واضح بالخدمة | استفسارات أصحاب العقارات |
| معلومات عملية | خطوات معاينة وأسئلة للمكتب | تسهيل قرار العميل |

هذا مقترح تحريري، وليس جدولاً منشوراً أو وعداً بنتائج. مواعيد النشر تُحدد بعد الاطلاع على بيانات الصفحة.

## قياس النتائج

ضع `metrics.json` في مجلد الحملة: مصدر الأرقام، تاريخ الرصد، الوصول، المشاهدات، التفاعلات،
الاستفسارات، الاستفسارات المؤهلة، المعاينات، الصفقات، الإنفاق وعملته. لا تضع أسماء العملاء أو هواتفهم.
راجع تعريف كل مقياس في مصدره؛ الوصول والمشاهدات مقياسان مختلفان.

```sh
node marketing/bin/domus-marketing.mjs report my-next-property
node --test marketing/test/*.test.mjs
```

نسبة التفاعلات = التفاعلات / الوصول × 100؛ كلفة الاستفسار = الإنفاق / الاستفسارات.
الأرقام الناقصة أو المقام الصفري ينتجان `null`؛ لا تتعامل مع البيانات الناقصة كأنها صفر.
هذه نسب وصفية للأرقام المدخلة، ولا تثبت أن الإعلان سبب الصفقة.

## المونتاج والخدمات

استخدم محرك `engine/` الموجود وملفات `productions/` للتحرير والرندر.
`tools/video-ad-editor` مصدر الإصدار المثبت لاستخدام أدوات المونتاج المناسبة عند الحاجة؛ وجود المصدر
لا يعني تثبيت كل نماذج Python، أو DaVinci، أو إضافات Claude على جهاز Windows.
`tools/open-edit` مصدر Open Edit المرفق، وأدواته المحلية تُختبر منفصلة عن وظائف VEED/fal المدفوعة.
السكيل المرفق محفوظ كما وصل في `reference/skills/motion-reel/` كمرجع، بلا نسخة عالمية إضافية.

عند ربط النشر لاحقاً: تحقق من معرّف صفحة دوموس والصلاحيات ونتيجة الطلب الفعلية قبل تسجيل
`scheduled` أو `published`. لا تُعد المحاولة إن كانت نتيجة الطلب غير معروفة قبل فحص المنصة.
الترويج يحتاج تحديد الحساب والميزانية والعملة والمدة وموافقة عليها؛ لا ميزانية مفترضة.
