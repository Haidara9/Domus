# Speed-ramp recut of an existing edit

**What:** Re-cut a finished landscape edit into a 9:16 reel: pick 2-4 s windows per space, give every moving shot a ramp preset
(`drone-glide` for the opener, `s-curve` for walk-throughs, `punch-in` into rooms, `punch-out` for the last shot), use push-ins on static
shots, put a whoosh on every cut that lands in a fast part, label spaces with `lowerThird`, close on dip-to-paper + `endCard`.

**Tip:** corner labels burned into a 16:9 source fall outside a centered 9:16 crop. Hide brand labels in the 16:9 version with
`byFormat: {"wide-16x9": {"hidden": true}}`.

**Proven in:** 2026-10-haydara-domus.
