# Carousel → motion film

**What:** Turn a DOMUS social carousel into a reel: one chapter per slide (about 4.6 s), built from the brand grammar
(paper → line-art draws → bracket draws → headline rises → rule grows → body settles → counter). The logo
end card follows with the services line and the location in copper.

**Settings:** `productions/2026-10-domus-brand-statement/timeline.json` (brandStatement at `[0.87, 0.25]`,
`width 0.80`, `bodySize 40`; archLines at `y 0.985`, `scale 1.35`; counter; endCard). Sound: `pad` + `air`
bed, `swell` into each chapter, a `click` when each counter number lands, a soft `impact` (46 Hz) plus a `shimmer`
on the logo sweep.

**When:** brand statements, values, services, "who we are". Not for listings, where the footage must lead.

**Proven in:** 2026-10-domus-brand-statement.
